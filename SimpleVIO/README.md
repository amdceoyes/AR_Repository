# SimpleVIO: 基于状态驱动的视觉-惯性 AR 追踪引擎

## 1. 项目简介
本项目旨在解决移动端 AR 在剧烈运动或视觉遮挡下的“漂移”与“丢失”问题。通过整合 **ORB 特征提取**、**PnP 位姿解算**与**惯性测量单元 (IMU)**，构建了一套具备故障自愈能力的空间定位系统。

## 2. 系统架构 (Pipeline)
系统采用模块化设计，数据流遵循以下路径：
`图像采集` -> `ORB 特征匹配` -> `PnP 位姿解算` -> **`FSM 状态机调度`** -> `IMU 滤波融合` -> `AR 渲染`



## 3. 核心模块说明
* **Vision Module**: 基于多层图像金字塔的 ORB 提取，确保不同距离下的追踪稳定性。
* **Tracking FSM**: 核心状态机，管理 `INIT` (初始化)、`TRACKING` (稳定)、`LOST` (惯性预测) 与 `RECOVERING` (回环找回) 四种状态。
* **IMU Processor**: 实现 $\theta + \omega \cdot \Delta t$ 运动学模型，在视觉丢失时提供毫秒级姿态补偿。
* **Mapping & Loop**: 维护关键帧字典，通过 BoW 或描述子匹配实现全局重定位。

## 4. 系统特点
1. **高鲁棒性**：状态机确保系统在视觉失效时不会立即崩溃，而是进入 5 秒的惯性盲区预测。
2. **低延迟**：模块化解耦方便后续针对 NPU/GPU 进行异构加速。
3. **可解释性**：全日志记录状态转换过程，便于调试与性能评估。
